# nixre.dev

> **Official website and landing page for Nixre ([nixre.dev](https://nixre.dev)).**

Nixre is a sovereign, self-hosted Git forge: its own Node.js core over PostgreSQL, bare repos on your disk, Git over HTTPS and SSH, passkey login, pull requests, and an embedded multi-provider AI assistant with an agentic tool loop.

---

## 🤖 AI Agent Friendly (llms.txt)

This site serves an official [`llms.txt`](./llms.txt) specification, synced automatically from the [main repository](https://github.com/Akicou/Nixre). AI agents and coding harnesses can read `/llms.txt` to autonomously deploy Nixre, configure custom subdomains, configure Let's Encrypt SSL, and diagnose router port forwarding settings (including Sunrise Connect Box 3).

---
