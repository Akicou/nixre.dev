# nixre.dev

> **Official website and landing page for Nixre ([nixre.dev](https://nixre.dev)).**

Nixre is a sovereign, minimalist, and ultra-fast code collaboration Git forge.

---

## 🤖 AI Agent Friendly (llms.txt)

This site serves an official [`llms.txt`](./llms.txt) specification. AI agents and coding harnesses can read `/llms.txt` to autonomously deploy Nixre, configure custom subdomains, configure Let's Encrypt SSL, and diagnose router port forwarding settings (including Sunrise Connect Box 3).

- **Vercel**
- **GitHub Pages**
- **Caddy / Nginx**
