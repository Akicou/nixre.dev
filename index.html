Self-hosted Git

A Git forge you run yourself. Passkeys, pull requests, an AI agent on your code.

Nixre is a small, complete Git server with a readable UI. Clone over HTTPS or SSH, review diffs, and put an AI assistant on your repositories — with your own API key, encrypted on your server. No vendor account, no third-party forge underneath.

Open the live instance Install it yourself

What it is

Most hosted forges trade convenience for lock-in. Nixre is the opposite: one compose file, your disk, your domain. The backend is a small Node.js service over PostgreSQL; repositories are plain bare Git repos on your disk, served over Smart HTTP and SSH by Nixre itself. There is no third-party forge underneath.

Auth is email + password sessions or personal access tokens. Passkeys are first-class: register Touch ID, Face ID, Windows Hello, or a hardware key and use it to start a fresh login. Everything account-scoped — settings, chats, keys — syncs across your devices through Nixre's own sync service.

A public instance runs at git.nayhein.com. The source is at github.com/Akicou/Nixre.

What you get

The parts people actually use. Nothing else is advertised.

Git over HTTPS & SSH
Standard git clone and git push. Smart HTTP from the core service, SSH from its own container. Automatic TLS when you put Caddy in front.
Spaces & repos
Organizations that hold repositories and members, branches, and push webhooks. Plain bare repos on your disk.
Pull requests
Branch compare, unified diff per file, merge. Plus an assistant panel that reads the actual diff and reviews it with you.
Passkeys
WebAuthn / FIDO2 as a real login method — Touch ID, Face ID, Windows Hello, or a hardware key starts a fresh session. Passwords and personal access tokens remain full fallbacks.
AI assistant
Bring your own key (DeepSeek, OpenAI, Anthropic, Ollama, any OpenAI-compatible endpoint) — stored AES-256-GCM encrypted server-side, never sent to the browser. Ask / Plan / Agent / Debug modes; Agent runs sandboxed repo tools (read, search, list files, run commands in a disposable clone) gated by per-repo permissions. Long chats auto-compact so context survives.
Closing signups
An admin toggle hides the registration page per browser. To close the API too, block POST /api/v1/register at your reverse proxy.
Agent notes
A machine-readable llms.txt covers deploy, DNS, Caddy patterns, and home-router port forwarding.

Install

Docker is the only dependency. Domain and TLS are optional on day one.

  1. 1. Clone

    Get the repo onto the machine that will host it.

  2. 2. Start

    docker compose up -d brings up Postgres, the API, git SSH, and the UI. Migrations run automatically.

  3. 3. Open it

    Visit http://localhost:3000, register the first account, and add an AI provider if you want the assistant.

  4. 4. Point a domain later

    A record to the host, forward 80/443, put Caddy in front. Certificates issue themselves.

# clone and start
$ git clone https://github.com/Akicou/Nixre.git
$ cd Nixre
$ docker compose up -d

# check it
$ curl -I http://localhost:3000
HTTP/1.1 200 OK

If an agent is installing this

Read /llms.txt first. It has the Caddyfile, the DNS records, and the Sunrise / DS-Lite notes so you don’t have to invent a deploy path.
