Self-hosted Git

A Git forge you run yourself.

A look inside

What you get

  • Git over HTTPS and SSHStandard git clone and git push. Use an access token as the password.
  • Pull requestsPer-file diffs, merge or squash, and required checks. An assistant panel reads the diff with you.
  • ActionsWorkflows in .nixre/workflows run on push, pull request, cron or by hand, in throwaway containers.
  • DeploymentsRun any Dockerfile from a repo as a service: auto-deploy, live logs, custom domains, uptime charts.
  • Security scanEvery few hours it checks what you run for known CVEs and files issues with the fix.
  • PasskeysLog in with Touch ID, Windows Hello or a hardware key.
  • AI assistantBring your own key (OpenAI, Anthropic, DeepSeek, Ollama or any compatible endpoint), encrypted on your server. Ask, Plan, Agent and Debug modes.

Install

Docker is the only dependency.

# set NIXRE_INTERNAL_TOKEN, NIXRE_AI_SECRET and POSTGRES_PASSWORD in .env first
$ git clone https://github.com/Akicou/Nixre.git
$ cd Nixre && cp .env.example .env
$ docker compose up -d

$ curl -I http://localhost:3000
HTTP/1.1 200 OK

Open localhost:3000 and register. The first account becomes the admin. The full guide, with domains and TLS, is in the README. Agents installing this should read /llms.txt.

A live instance runs at git.nixre.dev. It is a personal instance with registration closed, hosting the owner's projects and invited collaborators only. Source: github.com/Akicou/Nixre.
