Quick Start

From zero to forge
in thirty seconds.

Runs on a Raspberry Pi, a VPS, or your home server behind any ISP router. Zero dependencies beyond Docker.

1

Clone the repository

Grab the source from GitHub. git clone and you're halfway there.

2

Start the stack

One command spins up the Go backend, SQLite database, and Caddy reverse proxy with automatic HTTPS.

3

Point your domain

Add an A record at your registrar, configure port forwarding on your router, and Caddy handles the rest — including SSL.

4

Register your passkey

Head to Settings → Passkeys and enroll Touch ID, Face ID, or your YubiKey. Done.

terminal — zsh
# 1. Clone
$ git clone https://github.com/Akicou/Nixre.git
$ cd Nixre

# 2. Start
$ docker compose up -d

# 3. Verify
$ curl -I http://localhost:3000
HTTP/1.1 200 OK

# 4. Point your domain in Caddyfile
git.example.com {
  reverse_proxy 127.0.0.1:3001
}

$ sudo systemctl restart caddy
✓ Certificate issued. Forge is live.
